# Hearth

A journal that listens. Built for freelancers who work alone : track your energy, spot hidden patterns, and get one small thing to try tomorrow.

Exchange diary lets you share pages with a friend.

Built with the [DeepSpace SDK](https://docs.deep.space/).

**Live: [hearth.app.space](https://hearth.app.space)**

## Features

- Voice or text journaling with AI reflection and mood tagging
- Pattern analysis: what lifts you, what wears you down, with evidence
- Atomic Habits suggestions tied to your own data
- Exchange diary with a friend — ruled paper, photos, replies
- Weekly letter from Hearth summarizing your patterns
- Crisis-safe: 988 resources shown when needed

## Development

npm install
npx deepspace dev start

## Deployment

npx deepspace deploy
